EARTH FM - fixes (extract over integration-work/, overwrite src\)

1. data/earthDataEngine.ts  - SST + biosphere are PLANAR (class plane then value plane); engine read them interleaved. Fixed in sample() and getEquirectangularCanvas(). This was the "SST always 0.0 / chlorophyll 0%" bug and the blocky all-blue globe.
2. Mojibake: ┬░ -> °, ΓÇª -> …, Γÿà -> ★, ├ù -> x (App, CyberEarth, HudTelemetryLeft, HudRightPanel, NasaLoaderDrawer).
3. components/CyberEarth.tsx - Three.js loop used stale probeLat/probeLon/isScanPlaneActive (effect ran once); now read via refs. Reticle callback throttled to >=1px moves (was re-rendering the entire app at 60fps).
4. App.tsx - onProbeChange wrapped in useCallback (autoplay effect was re-running on every render).
5. components/HudTelemetryLeft.tsx - smoothing loop stops re-rendering once values converge.
6. Header: frame sliders now one line each (SST / AERO / CO2 / BIO) so the 2x2 grid fits inside the original 48px bar; status badge only shows while loading or on error. Full names are in the hover tooltip.
7. CO2: texture colours now match the legend (emerald->amber->magenta); no-plume areas read "<=380 ppm - NO PLUME" instead of UNAVAILABLE, and the CO2 sub-drone stays alive there.

(Audio engine change was reverted at the user's request - the audio is the original ThemedChordEngine again.)
9. Satellite signal route (auto-play): globe now centers the satellite (rotation was missing -90deg, parking it on the right edge); shortest-angle rotation so it does not spin the long way across 180deg longitude; arc is built once per route instead of every frame; probe updates only when the satellite moved >=0.2deg.
10. Globe controls: plain drag now spins the globe (was Alt/right-click only); click places the probe; Shift+drag scrubs the probe; vertical tilt is clamped; auto-play no longer fights your drag; right-click menu suppressed.

11. Place names: new data/placeNames.ts (seas/oceans by box, ~230 land points, natural regions). Replaces the old 'Continental Land Mass' fallback, which the narrator mispronounced as 'Massachusetts'. Labels, telemetry panel, transcript and narrator now say e.g. Arabian Sea, India, Sahara Desert, Gulf of Mexico.
12. Auto-play labelling: while ROUTE AUTO-PLAY runs, the globe callout and the narrator say only 'Above the Indian Ocean' (no coordinates). Narrator rewritten: speaks whenever the place changes, one pending timer always speaks the LATEST place (it used to skip places and sometimes never speak), min 3.5 s gap.
13. Hover scan: the probe now follows the mouse over the globe (no clicking). Toggle with the HOVER SCAN chip on the globe or the H key. Drag still rotates, click still pins, Shift+drag still scrubs. Off during auto-play.
14. Accessibility: fonts ~2px larger everywhere (header kept at its original size), side columns 310->346px, visible yellow keyboard focus, aria-labels/aria-pressed on every control, cards/presets reachable by keyboard, sr-only live place announcement, hover announcer (data: accessibility/useHoverAnnouncer.ts) - with NARRATOR on, resting the pointer on (or tabbing to) any button/slider says its short name. Keys: N narrator, H hover scan, R route auto-play, Space audio, 1-4 layers, arrows move probe.
15. Biosphere sound: (a) it only played when the probe moved (one note per 3 s update) - it is now a step sequencer that plays continuously: land = kalimba, ocean chlorophyll = glassy bell dyads; pitch height AND note density follow the data (rescaled: land greenness peaks ~130/255 and chlorophyll runs ~50-220, so both now use the full 0-1 range). (b) ice/snow (grey on the map) is silent.
16. Sea ice: the SST file holds colour-bar artefacts under Arctic/Antarctic sea ice (up to ~28 C at the North Pole), which played warm ocean chords over the grey ice. SST is now unavailable under sea ice (readout, sound AND the SST globe layer). New surface type OCEAN / COAST / LAND / SEA ICE / ICE-SNOW shown in the readout badge.

17. Mixer: faders, mute and solo now change the sound immediately while you drag (they used to be applied only the next time the probe moved). audio/ThemedChordEngine.ts
18. 3D SCAN is now a bulging wireframe (visual only): a thin glowing lat/lon line mesh (every 3 degrees) wraps the globe. Each grid point is lifted by the real NASA value under it and coloured with the layer legend colours (ocean = SST, land = biosphere, strong aerosol / CO2 plumes take over). A band sweeps pole to pole: lines it touches flare and lift, and a readout shows the average SST / aerosol / CO2 / biosphere along the band. While it is on, the flat painted layers are hidden. Switch it off to get them back. components/dataScanGrid.ts (new), CyberEarth.tsx, HudTopHeader.tsx, data/earthDataEngine.ts (sample() can skip place names), styles/cyberHud.css
19. Start screen: Earth FM logo over drifting stars, shooting stars and asteroids. Click or any key enters and unlocks audio. components/IntroSplash.tsx, App.tsx, styles/cyberHud.css, public/earth-fm-logo.png, src/vite-env.d.ts
